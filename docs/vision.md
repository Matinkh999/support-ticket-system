# Project Vision
## Support Request Tracking System

### 1. Project Overview
The Support Request Tracking System is designed to provide an independent and centralized platform for managing support requests. Its main purpose is to prevent requests from being scattered across emails and messaging applications and to ensure that every request can be tracked from submission to closure.

### 2. Project Goals
The main goals of the system are:
- Centralize support requests in one platform.
- Improve the tracking and management of requests.
- Reduce forgotten or unanswered requests.
- Improve the clarity and quality of support responses.
- Make request priorities and responsible support agents clear.
- Help managers monitor the support process.

### 3. Stakeholders and Users

**Support Manager**
- Monitors support agents and their handling of requests.
- Supervises the quality and clarity of responses.
- Oversees the overall support process.

**Support Agent**
- Reviews and handles assigned requests.
- Provides clear and complete responses.
- Updates request statuses and follows requests until closure.

**Customer**
- Submits questions, problems, and support requests.
- Tracks request status.
- Receives responses and provides additional information when necessary.

### 4. Problems to Be Solved
The system aims to address the following problems:
- Difficulty tracking the status of support requests.
- Unclear or incomplete responses from support agents.
- Lack of clarity about who is responsible for each request.
- The possibility of requests being forgotten, especially urgent ones.

### 5. Project Scope

The system will provide the following core features:
1. Creating support requests with a title, description, category, and urgency level.
2. Assigning requests to support agents.
3. Managing request statuses.
4. Recording response notes for each request.
5. Displaying an agent's open requests in priority order.
6. Generating reports on open, closed, and answered requests within a selected time period.

**Additional Feature:**
- Allowing customers to attach relevant files and images to their requests.

### 6. Out of Scope
The following features are not included in this project:
- Telephone and SMS support services.
- Network and equipment monitoring.
- Salary calculation and employee performance evaluation.
- Knowledge base and user training services.

### 7. Project Vision Statement
The vision of this project is to create a simple and centralized support management system that improves communication between customers, support agents, and managers, while ensuring that requests are handled clearly, efficiently, and in an organized manner.
